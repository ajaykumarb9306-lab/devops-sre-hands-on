# AWS S3

S3 provides object storage.

## Common Uses

- Application artifacts
- Backups
- Logs
- Static content
- Terraform state
- Data storage

## Commands

List buckets:

aws s3 ls

List objects:

aws s3 ls s3://BUCKET_NAME

Upload:

aws s3 cp FILE s3://BUCKET_NAME/

Download:

aws s3 cp s3://BUCKET_NAME/FILE .

Synchronize:

aws s3 sync DIRECTORY s3://BUCKET_NAME/

## Security

Review:

- Bucket policies
- IAM permissions
- Public Access Block
- Encryption
- Versioning
- Lifecycle policies

Avoid public access unless intentionally required.
