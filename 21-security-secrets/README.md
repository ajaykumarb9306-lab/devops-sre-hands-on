# Security & Secrets

Security is part of every DevOps and SRE workflow.

This module covers:

- Secrets management
- Environment variables
- Git secret protection
- Kubernetes Secrets
- Least privilege
- Credential rotation
- Secret scanning
- Incident response
- Secure CI/CD practices

## What Is a Secret?

Examples:

- Passwords
- API keys
- Access tokens
- Database credentials
- Private keys
- Cloud credentials
- Service account credentials

Secrets should never be hard-coded into application code or committed to Git.
