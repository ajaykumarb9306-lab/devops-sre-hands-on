# Azure FinOps

FinOps combines engineering, finance, and operational practices to improve cloud cost visibility and efficiency.

## Areas to Review

- Azure Cost Management
- Budgets
- Cost allocation
- Tags
- Rightsizing
- Reservations
- Savings Plans
- Idle resources
- Storage optimization
- Cost anomalies

## Optimization Flow

Azure Spend
    |
Cost Visibility
    |
Allocation
    |
Utilization
    |
Optimization Opportunity
    |
Engineering Review
    |
Implementation
    |
Savings Validation

## Common Opportunities

- Oversized VMs
- Idle VMs
- Unattached managed disks
- Unused public IPs
- Old snapshots
- Inefficient storage tiers
- Missing tags
- Stable workloads suitable for commitments

## FinOps Principle

Cost optimization should consider:

- Reliability
- Performance
- Capacity
- Availability
- Business requirements
- Disaster recovery

The cheapest configuration is not automatically the correct configuration.
