# Grafana

Grafana visualizes metrics and other observability data.

## Common Data Sources

Prometheus
Loki
Elasticsearch
CloudWatch
Azure Monitor
Google Cloud Monitoring

## Dashboard Examples

Infrastructure Health
Application Performance
Kubernetes
Database Performance
Network Health
SLO Dashboard

## Useful Panels

CPU utilization
Memory utilization
Request rate
Error rate
Latency
Availability

## SRE Dashboard Principle

A dashboard should help answer operational questions quickly.

Avoid creating dashboards containing large numbers of metrics without clear operational purpose.
