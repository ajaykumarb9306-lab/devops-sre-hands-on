# Incident Triage

## First Questions

1. What is broken?
2. Who is affected?
3. When did it start?
4. Is the problem still happening?
5. What changed recently?
6. Is it isolated or widespread?

## Determine Scope

Check whether the issue affects:

- One user
- One application
- One host
- One availability zone
- One region
- All users

## Check Recent Changes

Investigate:

- Deployments
- Configuration changes
- Infrastructure changes
- DNS changes
- Firewall changes
- Certificate changes
- Database changes

## Mitigation vs Root Cause

During a major incident, restoring service may be the immediate priority.

Mitigation:

Restore service quickly.

Root Cause Analysis:

Determine why the incident occurred and how recurrence can be prevented.
