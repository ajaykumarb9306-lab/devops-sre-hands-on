# CI/CD Concepts

## Pipeline

A pipeline is an automated sequence of build, test, validation, and deployment steps.

## Trigger

A trigger starts a pipeline.

Examples:

- Git push
- Pull request
- Tag
- Manual execution
- Scheduled execution

## Job

A job contains a collection of pipeline steps.

## Step

A step executes an action or command.

## Runner

A runner is the machine that executes the pipeline.

GitHub Actions commonly uses:

ubuntu-latest

## Artifact

An artifact is an output generated by a pipeline.

Examples:

- Application package
- Docker image
- Test report
- Compiled binary

## CI

Continuous Integration validates changes frequently.

## CD

Continuous Delivery prepares validated changes for deployment.

Continuous Deployment can automatically release validated changes.

## Secrets

Credentials must be stored using the CI/CD platform's secret management system.

Never hard-code:

- Cloud credentials
- API tokens
- SSH private keys
- Registry passwords
